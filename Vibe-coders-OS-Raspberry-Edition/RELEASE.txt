Vibe-coder's OS — Raspberry Edition 1.3.0

Office & Creative Edition

Added to the Raspberry Pi image layer:
- LibreOffice Writer, Calc, Impress, Draw, Base and Math
- LibreOffice GTK integration and help content
- Evince PDF/document viewer
- KolourPaint lightweight Paint-style editor
- GIMP image editor
- Inkscape vector graphics editor
- CUPS printing stack and system-config-printer
- Thunderbird mail/calendar client

The root filesystem image size was increased from 12 GiB to 16 GiB to provide practical headroom for the larger desktop/application stack.

Target remains Raspberry Pi 3 Model B+ ARM64 / Debian Trixie / Wayland-labwc.
